# Trabalho 06 - Alocação de Memória

## Objetivo
Implementar um alocador simples para páginas ou blocos de memória física usados pelo kernel.

## Tarefas
1. Definir a área de memória disponível para alocação.
2. Implementar alocação alinhada a página.
3. Zerar memória alocada quando exigido.
4. Detectar esgotamento de memória.
5. Evitar sobrepor kernel, stack e estruturas estáticas.

## Submissão
Envie fonte compactado ou `kernel.elf`.

## Critérios de avaliação
- **Estrutura da submissão:** 2 pontos.
- **Build ou ELF válido:** 2 pontos.
- **Endereços retornados são alinhados:** 2 pontos.
- **Múltiplas alocações não se sobrepõem:** 2 pontos.
- **Esgotamento e limites tratados corretamente:** 2 pontos.

## Nota
A nota será de 0 a 10. O avaliador poderá executar testes injetados de alocação.
