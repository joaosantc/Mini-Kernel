# Trabalho 10 - Modo Usuário

## Objetivo
Executar aplicações em U-mode, separando código de usuário do kernel em S-mode.

## Tarefas
1. Preparar contexto para retorno com `sret`.
2. Configurar `sstatus`, `sepc` e stack de usuário.
3. Marcar páginas de usuário com permissão adequada.
4. Demonstrar execução em modo usuário.
5. Tratar tentativas de instrução privilegiada como exceção controlada.

## Submissão
Envie fonte compactado ou `kernel.elf`.

## Critérios de avaliação
- **Estrutura da submissão:** 2 pontos.
- **Build ou ELF válido:** 2 pontos.
- **Transição para U-mode funciona:** 3 pontos.
- **Isolamento básico de privilégio funciona:** 2 pontos.
- **Diagnóstico de exceção é claro:** 1 ponto.

## Nota
A nota será de 0 a 10.
