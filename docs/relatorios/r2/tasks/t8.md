# Trabalho 08 - Tabela de Páginas

## Objetivo
Implementar tabelas de páginas Sv32 para mapear endereços virtuais em endereços físicos.

## Tarefas
1. Criar estruturas e macros para PTEs Sv32.
2. Implementar mapeamento de páginas.
3. Configurar flags de leitura, escrita, execução e usuário quando necessário.
4. Ativar paginação via `satp`.
5. Garantir que o kernel continue executando após ativar a MMU.

## Submissão
Envie fonte compactado ou `kernel.elf`.

## Critérios de avaliação
- **Estrutura da submissão:** 2 pontos.
- **Build ou ELF válido:** 2 pontos.
- **Mapeamentos Sv32 corretos:** 3 pontos.
- **Kernel continua executando com paginação ativa:** 2 pontos.
- **Acessos inválidos geram exceção controlada:** 1 ponto.

## Nota
A nota será de 0 a 10. O avaliador poderá testar acessos válidos e inválidos.
