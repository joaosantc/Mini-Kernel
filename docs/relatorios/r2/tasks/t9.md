# Trabalho 09 - Aplicações

## Objetivo
Adicionar suporte a aplicações separadas do kernel, com código de usuário preparado para ser executado pelo sistema.

## Tarefas
1. Criar arquivos de usuário quando aplicável, como `user.c`, `user.h` e `user.ld`.
2. Definir ponto de entrada da aplicação.
3. Incluir ou carregar a aplicação no kernel.
4. Preparar contexto inicial para execução da aplicação.
5. Produzir saída observável da aplicação.

## Submissão
Envie fonte compactado ou `kernel.elf`. Inclua arquivos de usuário se usar build local.

## Critérios de avaliação
- **Estrutura da submissão:** 2 pontos.
- **Build ou ELF válido:** 2 pontos.
- **Aplicação possui ponto de entrada correto:** 2 pontos.
- **Kernel inicializa e executa a aplicação:** 3 pontos.
- **Saída da aplicação é identificável:** 1 ponto.

## Nota
A nota será de 0 a 10.
