## Faculdade de Computação

### Trabalho 01 - Boot do Kernel

#### Objetivo
Implementar o boot mínimo do kernel RISC-V usado no projeto *Operating System in 1,000 Lines*. O kernel deve ser carregado pelo OpenSBI no QEMU e transferir a execução para `kernel_main`.

---

#### Tarefas
1. Criar o linker script com entrada em `boot`.
2. Posicionar o kernel em `0x80200000`.
3. Implementar a função `boot` na seção `.text.boot`.
4. Configurar o registrador `sp` para o topo da pilha.
5. Saltar para `kernel_main`.
6. Inicializar a região `.bss`.

---

#### Submissão
Envie um arquivo `.zip`, `.tar.gz` ou `kernel.elf`. O envio de `elf` é permitido para agilizar a avaliação, mas o professor pode exigir recompilação local.

---

#### Critérios de avaliação
* **Estrutura e arquivos esperados:** 2 pontos.
* **ELF válido para RISC-V 32-bit:** 2 pontos.
* **Entrada em `0x80200000`, símbolos `boot` e `kernel_main`:** 3 pontos.
* **Execução no QEMU sem reboot inesperado:** 2 pontos.
* **Organização mínima:** 1 ponto.

---

#### Nota
A nota será de 0 a 10. Submissões que não compilam ou não fornecem um ELF válido terão nota máxima 2.
